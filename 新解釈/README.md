# 漸化式の新解釈

高校数学の漸化式を、線形代数と複素平面から読み直す独立した教科書の草案。
初稿作成日：2026年10月15日。

## 構成

1. はじめに（対象読者、読み方、記号と表記）
2. 線形代数と漸化式（予備知識、特性方程式、連立、高階）
3. 複素平面と漸化式（予備知識、1次分数変換、非実数の特性根、三角関数、回転と行列の合流）

本文は高校数学の基本的な式計算を前提とし、行列・固有値などは導入から説明する。
定数係数の線形漸化式を中心に、変数係数の場合との違いも明記する。
演習集ではなく、具体例を複数の視点から読み直す構成としている。

## 組版とビルド

入口は「漸化式の新解釈.tex」。このディレクトリで「latexmk 漸化式の新解釈.tex」を実行する。
upLaTeX と dvipdfmx、および既存の発展版と同じTeXパッケージを使用する。
リポジトリ共通の「../tex/book-links.tex」を読み込む。

preamble.tex は発展版の2026年10月15日時点（68cb7492）の設定を継承する。
A4実寸、10pt、余白20mm、本文2段組、段間罫線、見出し・参照形式を維持する。
図は figures/diagrams.tex、本文は章・節ごとに分ける。
PDFとコンパイル中間ファイルはコミットしない。
