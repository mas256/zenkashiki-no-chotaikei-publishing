# 漸化式の新解釈

高校数学の漸化式を、線形代数と複素平面から読み直す独立した教科書。
初稿：2026年10月15日。再構成：2026年10月29日。

## 構成

1. はじめに：対象読者・構成・記号。
2. 行列と連立漸化式：和と差から固有値・対角化へ進み、不動点と定数項を扱う。
3. 隣接多項間漸化式：連立表示、補助数列、重解、差分による項数の削減、一般化。
4. 複素平面と漸化式：極形式、行列との対応、非実数の特性根と回転。
5. 一次分数型と連立漸化式：成分比、不動点、差の比、単位円、一つの例による統合。
6. 三角関数と漸化式：一定角の回転と整数倍角を比較し、チェビシェフ多項式へ進む。

前の章で使った具体例と概念を次の章で読み直す。
行列・固有値・複素平面は導入から説明する。数列・二次方程式・三角関数は前提とする。
本編の付録から独立して読める内容とし、定数係数の線形漸化式とその成分比を中心に扱う。
最終章では非線形の角度倍増へ範囲を広げ、一定角の回転との違いを説明する。

## 組版とビルド

入口は `漸化式の新解釈.tex`。このディレクトリで `latexmk 漸化式の新解釈.tex` を実行する。
upLaTeX と dvipdfmx、および既存の発展版と同じ TeX パッケージを使う。
共通の `../tex/book-math.tex`、`../tex/book-links.tex`、`../tex/book-toc.tex` を読み込む。
句読点後の空白は `../scripts/tex-spacing.py` がビルド時に自動挿入する。

A4実寸、10pt、余白20mm、本文2段組、段間罫線を維持する。
`python3 build-mobile.py` で、同じ原稿から90×160mm・1段組のスマホ版を作る。
出力先は `../out/new-interpretation-mobile/mobile.pdf`。
内部では `\BookMobile` を定義した入口を生成して全章に適用する。
図は `figures/diagrams.tex`、本文は章・節ごとに分ける。
PDFとコンパイル中間ファイルはコミットしない。
