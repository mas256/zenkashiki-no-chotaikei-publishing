\subsection{ガウス記号を含む式}\label{節：ガウス記号を含む式}
ここではガウス記号を含む\bookterm{recurrence}{漸化式}を扱う.
ガウス記号を含む漸化式は,記号があるからといって解法が1つに決まるわけではない.
項の値を整数にするために使われることもあれば,参照する添字を指定したり,余りを表したりするのに使われることもある.
したがって,式変形だけでなく,整数の性質や不等式,偶奇,数え上げといった考え方が必要になる.
大事なのは,\textbf{ガウス記号が式の中で何をしているのか}を見極めることである.
以下では,その役割ごとに10個の使い方を例題とともに紹介しよう.

\subsubsection{基本性質と使い方}\label{節：基本性質と使い方}
\bookterm{floor}{ガウス記号}$\lfloor x\rfloor$または$[x]$は,実数$x$を超えない最大の整数を表し,\bookterm{floor-function}{床関数}と呼ばれる.\footnote{対になる記号として,天井関数$\lceil x\rceil$は$x$以上の最小の整数を表す.
  整数$k$について$\lceil x\rceil=k\iff k-1<x\le k$である.以下の例題では床関数を使う.}
整数$k$について,
\[
  \lfloor x\rfloor=k\iff k\le x<k+1
\]
である.\,$x\ge0$では小数点以下の切り捨てに一致するが,負数では$\lfloor-1.5\rfloor=-2$となる.

\BookFigFloorGraph

問題を見たら,まず\bookterm{floor-function}{床関数}が\textbf{項の値,添字,付加項のどれに作用しているか}を確かめよう.
その役割によって,次のように方法が分かれる.
\begin{enumerate}[label=(\arabic*)]
  \item 整数性・不等式で整数部分を確定する.
  \item 同じ値を取る区間を群としてまとめる.
  \item 余りを取り出し,有限個の値と周期を調べる.
  \item \bookterm{floor-function}{床関数}の差で境界・条件・繰り上がりを検出する.
  \item 丸め誤差と係数の関係を使う.
  \item 整数への丸めで\bookterm{fixed}{不動点}と停止を調べる.
  \item 添字を二つに分割する.
  \item 商と余りで整数の桁を読む.
  \item 小数部分を残し,回転として読む.
  \item 条件を満たす整数や格子点の個数を数える.
\end{enumerate}
ここでは\bookterm{general}{一般項}だけでなく,周期や止まる値,数えている対象そのものを求める問題も扱う.

なお,整数$k$については$\lfloor x+k\rfloor=\lfloor x\rfloor+k$だが,実数同士では$\lfloor x+y\rfloor=\lfloor x\rfloor+\lfloor y\rfloor$とは限らない.
また,ガウス記号を含む漸化式では,数項を計算する実験が特に有効である.
ただし,実験から得た予想は,不等式や数学的帰納法できちんと確かめること.

\medskip
\paragraphbf{着眼点のまとめ}
ガウス記号を見たら,まずそれが何に作用しているかを確かめ,その役割から方法を選ぶ.
また,余りと桁,群数列と数え上げは,同じ量を別の側から数えているにすぎない.
1つの問題を2通りに見られるようになると,ガウス記号の問題はぐっと楽になるだろう.
