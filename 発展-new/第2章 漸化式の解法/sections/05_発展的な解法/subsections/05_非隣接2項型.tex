\subsection{非隣接2項型}\label{節：非隣接2項型}

今までの漸化式は,隣り合う項どうしの関係であったが,1つ飛ばしの項どうしの関係はどうだろうか.
一般的な形は
\[
  a_{n+2}=f(a_n)\qquad(n\ge1)
\]
で与えられる.

解法はいくつかある.順に見ていこう.
\subsubsection{偶奇で分ける}\label{節：偶奇で分ける}
  
  まずは実験してみよう.\,$a_1$から$a_3,a_5,\ldots$が決まり,\,$a_2$から$a_4,a_6,\ldots$が決まる.
  つまり,奇数番目と偶数番目は互いに全く関係なく,別々の数列として動いているのだ.
  そこで,\,$u_k=a_{2k-1},\ v_k=a_{2k}$と2つの数列に分けて考えてみよう.
  \[
    \begin{array}{c|cccc}
      k&1&2&3&\cdots\\ \hline
      u_k&a_1&a_3&a_5&\cdots\\
      v_k&a_2&a_4&a_6&\cdots
    \end{array}
  \]
  $n$が2進むと$k$は1進むので,
  \[
    u_{k+1}=f(u_k),\qquad v_{k+1}=f(v_k)
  \]
  という隣接2項間の漸化式になる.
  あとはそれぞれを解き,最後に奇数$n$では$k=\frac{n+1}{2}$,偶数$n$では$k=\frac{n}{2}$として$a_n$に戻せばよい.
  
  \begin{bookpoint}
    \textbf{POINT}\par
    奇数番目と偶数番目に分け,それぞれを隣接2項間の漸化式として解く.
  \end{bookpoint}

\subsubsection{隣接漸化式に変形する}\label{節：隣接漸化式に変形する}
  例えば
  \[
    a_{n+2}=4a_n
  \]
  のような漸化式は,\,$a_{n+1}$の係数を$0$と見ることで隣接3項型としても解ける.
\noindent \bookblocklink{example-nonadjacent-1}{problem}{answer}{【例題】}\par\nobreak
\begin{enumerate}[label=(\arabic*),parsep=3pt,format=\bookitemlink{example-nonadjacent-1}{problem}{answer}]
  \item $a_1=2,\,a_2=3,\,a_{n+2}=a_n^2$
  \item $a_1=1,\,a_2=2,\,a_{n+2}=2a_n+1$
  \item $a_1=1,\,a_2=3,\,a_{n+2}=4a_n$
\end{enumerate}

\noindent\bookblocklink{example-nonadjacent-1}{hint}{problem}{【方針】}\par\nobreak
\begin{enumerate}[label=(\arabic*),parsep=3pt,format=\bookitemlink{example-nonadjacent-1}{hint}{problem}]
  \item 奇数番目と偶数番目を別々の\bookterm{sequence}{数列}とみなし,それぞれの二乗関係を調べます.
  \item $b_n=a_n+1$とおいて定数項を消してから,奇数番目と偶数番目に分けます.
  \item $a_{n+2}=0\cdot a_{n+1}+4a_n$と見て,\bookterm{characteristic}{特性方程式}を解きます.
\end{enumerate}

\noindent\bookblocklink{example-nonadjacent-1}{answer}{problem}{【解答】}\par\nobreak
\begin{enumerate}[label=(\arabic*),parsep=3pt,format=\bookitemlink{example-nonadjacent-1}{answer}{problem}]
  \item $a_{2k-1}=2^{\,2^{k-1}},\quad a_{2k}=3^{\,2^{k-1}}\quad(k\ge1)$
  \item $a_{2k-1}=2^k-1,\quad a_{2k}=3\cdot2^{k-1}-1\quad(k\ge1)$
  \item $a_n=\frac54\,2^{n-1}-\frac14\,(-2)^{n-1}$
\end{enumerate}

\noindent\bookblocklink{example-nonadjacent-1}{solution}{problem}{【解法】}\par\nobreak
\begin{enumerate}[label=(\arabic*),parsep=3pt,format=\bookitemlink{example-nonadjacent-1}{solution}{problem}]
  \item $u_k=a_{2k-1},\,v_k=a_{2k}$とおくと,
    \[
      u_1=2,\quad v_1=3,\qquad
      u_{k+1}=u_k^2,\quad v_{k+1}=v_k^2
    \]
    となる.したがって,それぞれ順に2乗していくので,
    \[
      u_k=2^{\,2^{k-1}},\qquad v_k=3^{\,2^{k-1}}
    \]
    となり,\,$u_k=a_{2k-1},v_k=a_{2k}$で戻す.
  \item $b_n=a_n+1$とおくと,
    \[
      b_{n+2}=a_{n+2}+1=2a_n+2=2b_n
    \]
    であり,\,$b_1=2,\,b_2=3$である.
    よって,奇数番目と偶数番目で分けると,
    \[
      b_{2k-1}=2^k,\qquad b_{2k}=3\cdot2^{k-1}
    \]
    となる.\,$a_n=b_n-1$に戻せば【解答】を得る.
  \item \bookterm{characteristic}{特性方程式}は
    \[
      x^2-4=0
    \]
    であり,解は$x=2,-2$である.したがって,
    \[
      a_n=A\,2^{n-1}+B\,(-2)^{n-1}
    \]
    とおける.\,$a_1=1,\,a_2=3$を代入すると,
    \[
      A+B=1,\qquad 2A-2B=3
    \]
    より$A=\frac{5}{4},B=-\frac{1}{4}$と決まり,【解答】を得る.
\end{enumerate}

\subsubsection{一周期分をまとめる}\label{節：一周期分をまとめる}
では,奇数番目と偶数番目で漸化式そのものが変わる場合はどうだろうか.
この場合も,2回分の操作を1つにまとめてやれば,隣接2項間の漸化式になる.

\paragraphbf{例題：2回分をまとめる}
\[
  a_1=1,\qquad
  a_{n+1}=\begin{cases}
    2a_n+1&(n\text{が奇数}),\\
    3a_n+2&(n\text{が偶数})
  \end{cases}
\]
奇数番目を$x_k=a_{2k-1}$と置くと,\,$a_{2k}=2x_k+1$であり,
もう1回漸化式を用いて
\[
  x_{k+1}=3(2x_k+1)+2=6x_k+5
\]
を得る.これは特性方程式型なので,\,$x_1=1$から$x_k=2\cdot6^{k-1}-1$であり,
\BookMathLayout{\[
    a_{2k-1}=2\cdot6^{k-1}-1,\qquad
    a_{2k}=4\cdot6^{k-1}-1\quad(k\ge1)
  \]}{\[
    \begin{aligned}
      a_{2k-1}&=2\cdot6^{k-1}-1,\\
      a_{2k}&=4\cdot6^{k-1}-1\quad(k\ge1)
    \end{aligned}
  \]}
となる.偶数番目は$a_{2k}=2x_k+1$から求めた.
付加項の$1$も次の操作で3倍されるので,2回分の付加項は$1+2$ではなく$3\cdot1+2=5$になることに注意しよう.

\paragraphbf{1周期への拡張}
$a_{n+1}=p_na_n+q_n$の係数が周期$L$をもつなら,
$x_k=a_{1+kL}$ $(k\ge0)$と置き,\,$x_0=a_1$から一周期分を合成する.
\[
  x_{k+1}=Px_k+Q
\]
の$P$は係数$p_n$の積,\,$Q$は各付加項にその後の係数を掛けたものの和である.\footnote{最初の一周期の係数を$p_1,\ldots,p_L$, $q_1,\ldots,q_L$とすると,
  $P=\prod_{j=1}^L p_j$, $Q=\sum_{j=1}^L q_j\prod_{i=j+1}^L p_i$である.空積は$1$とする.
  この表示は係数に$0$を含む場合も成り立つ.}
途中の項は,元の漸化式を1回ずつ用いて求められる.
$P=0$なら$x_k=Q$ $(k\ge1)$,\,$P=1$なら$x_k=x_0+kQ$である.
それ以外は,\,\sectionref*{節：特性方程式型}と同じく不動点からの差を取る.

\begin{bookpoint}
  \textbf{POINT}\par
  漸化式が周期的に変わるなら,1周期分の操作をまとめて1つの漸化式にする.
\end{bookpoint}
ただし,漸化式の係数が周期的だからといって,項の値まで周期的になるわけではないので注意しよう.
付録の\sectionref*{節：2回分の漸化式をまとめる}では,同じ計算を行列の積で表す.
符号も変わる例は\bookproblemref{practice-connections}{4}{接続演習問4}へ.
