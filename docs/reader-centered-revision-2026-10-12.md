# 具体例から構造へ進む改訂

この記録は説明を補強した173ページ版のもの. その後の分量削減は[要点を保つ要約改訂](concise-text-revision-2026-10-13.md)を参照.

レビュー対象は公開171ページ版（`61e8ec9`）. 改訂ブランチは `revision/reader-centered-2026-10-12`.

本書の目的は,更新を観察し,追う量を変え,計算して元へ戻す過程から,解法どうしの構造とつながりを見渡すことである.
多角的な解釈・網羅性・抽象化は保持する. 今回は,一つの解法を経験する前に一般化が重なる箇所と,同じ数列の表示や添字が短い間隔で切り替わる箇所を中心に再編した.

## 編集の基準

- 最初の解法では,発想から計算,初期条件,復元までを一度つなげる.
- その後の別解・図形的解釈・一般化では,先の計算と何が同じで,何が新しく分かるかを示す.
- 一つの導出では,添字の起点と係数の役割を保つ. 同値な別表示は独立した補足で扱う.
- 操作の理由,適用条件,元へ戻す一歩は本文に残す. 追加の例外・証明・用語は必要に応じて注釈へ置く.
- 作者の説明を活用し,順序の変更,短い接続文,必要な一行の計算で見通しを作る.
- 難しい内容の有無やページ数だけで読みやすさを評価しない. 難所を支える説明と,読者が現在の対象を保持できるかを見る.

## 主な再編

| 箇所 | 改訂後の流れ |
| --- | --- |
| 追う量を変える | 引く・割る・まとめるという目標を先に示し,倍率から因子を作る理由と復元を結ぶ. 二項をまとめる係数比較を見える式にする. |
| 解を組み合わせる | 交互の二つの解→係数の重複→すべての解→必要な個数→一般の式へ. 三つの解の従属例は本文で経験してから一般定義へ進む. |
| 連立型 | 例題(1)を和と差で解き終える→対称な係数の一般形→一般の重み→例題(2)→最初の和と差を重みから見直す. 同じ和と差の再計算は集約した. |
| 重解 | 具体例の後で,倍率を取り除くと一定の階差が残り,一次式が掛かる理由を示す. 連立の重解からは既存の標準問25へ戻れる. |
| 虚数根 | 主導出・4例題・加法定理別解・振幅・周期・独立性の証明を `a_1,a_2`,指数 `n-1` に統一. 指数 `n` の別表示と第零項からの例は末尾に保持. |
| 行列による一次分数型 | 既存の数値例を先に置き,分子が2倍,分母の和が一定という計算から一般の固有方向の比へ進む. |
| 座標変換 | 新しい座標→元の座標→更新→新しい座標という順を式にして `Q^T A Q` を導く. |
| 補間 | 三点を通る複数の式を経験してから,次数を制限した一般の作り方と一意性へ. |
| カタラン数 | `n+1`個の因子の括弧付けを数える→最小例→最後の掛け算で左右へ分割→母関数→係数へ復元. |
| 完全順列 | 解答後の長い接続を,確率・収束・極限の値・個数の近さに区切る. 二つの極限の順序と証明は保持. |
| 用語と参考文献 | 73用語を六つの目印で整理. Web資料の対応を現行の節・図へリンクし,旧図番号の直書きをなくす. |

## 数学的な修正と補強

- 差分商は基点を固定した微分の極限として述べる. 基点も動く場合の一様近似には追加条件が必要であることを区別した.
- Newton法は,証明した「誤差が二乗の定数倍以下」という上界に結語を合わせる. 三次以上になる例も注釈に保持した.
- 二項係数の初出を説明し,範囲外を零とする規約と階乗表示の適用範囲をそろえた.
- 積の表示と,非零の因子で割る方法の条件を区別した.
- 正接の公式の定義域,複素数の負整数乗の非零条件,Pell方程式のパラメータ,互除法の終了条件を明示した.
- 応用問10の対数解法を保持し,`c_n=2^{n+1}b_n`で平方の更新へ直す別解を追加. 対数後に引く操作と,元の量に掛ける操作の対応を示した.
- 接続問2で,不変量から同じ係数の線形式が現れる変形を示し,初期値変更の問いを答案と同じ正値の範囲にした.
- 閉じた一般項,和・積による表示,周期・停止・整数性などの結論を区別. 分類図を可解性の保証ではなく,重なる着眼点の整理にした.

## 検証

最終PDFはA4 **173ページ**,スマホ版 **632ページ**. レビュー前は171ページ・619ページだった.

- 両版のビルド成功. 最終TeXログに未解決参照・数式のはみ出しなし.
- A4全頁のMediaBox/CropBoxと,スマホ版全頁の寸法を確認.
- フォントをすべて埋め込み,原ノ味フォントを確認.
- 既存ラベル173件,73用語,42資料,標準55題の順序を変更前と照合.
- 問題・解答等の682個の番号付きPDF移動先,手動式番号15個と往復リンクを確認.
- ヘッダー/フッターへ本文リンクが広がる領域は両版とも零. 新しいPDF検査は旧版の58・125・153頁の不具合を検出し,改訂版は通過した.
- 分割して置く例題は実際の番号集合で検査し,同番号の重複・番号の穴・答えとの不一致を拒否する.
- 各節の用語初出装飾,ガウス型10例,既存の漸化式接続を検証.
- 編集に参加しない数学担当が,付録の一般論・新別解・参照資料を再導出. 未解決の数学指摘なし.

初回統合PDFを,履歴を渡さず推論を浅く設定した基礎読者役と接続読者役に読ませた.

その結果を受け,二項の係数比較を補い,三つの数列の従属例と復元の十分条件の理由を本文へ移した.
行列の読書では入口の頁を省いた影響も確認し,前提を読んでから操作の理解と記号の記憶を区別した.
