# 文書方針に基づく「発展-new」のレビューと修正

## 対象と判断の根拠

対象は main の `b9f30581cee73ed05e217601d388a8f8b9cdbba0` にある「発展-new」。本文から読み込まれる88ファイルを確認し、そのうち44個のTeXファイルを修正した。読み込まれていない旧付録は対象に含めていない。

[文書レビューと執筆の基本方針](writing-policy.md)を基準とし、著者の『文書の書き方』と、基本四パターンまで著者が修正済みとした `review/2026-10-16` の説明を参照した。同ブランチ全体を著者だけの執筆とはみなしていない。

中心となる問題は、操作を要約する言葉が先に立ち、何を計算するのか、なぜその計算を選ぶのかを読者が補わなければならないことだった。用語そのものの削除ではなく、その箇所で必要な対象・操作・理由の説明を補った。

## 主な指摘と修正

| 箇所 | 元の記述・問題 | 修正 |
| --- | --- | --- |
| はじめに | 「更新」「観察」「変換」を並べて本書の目的を述べていた。何を理解する本なのかが伝わりにくい。 | 「何を見てその式変形を思いつくのか」「なぜそれによって解けるのか」を考える、と具体的にした。 |
| 等差型・等比型 | 代入がすぐ一般形へ進み、括弧の中へ直前の項を代入する過程が見えにくい。 | 第4項の計算を括弧つきで示してから、足す・掛ける回数を一般化した。要点の囲みは導出後に置いた。 |
| 階差型 | 「指数の差も足し戻せます」では、指数同士の差を計算するとも読める。 | 実際に足すものが $2^1+2^2+\cdots+2^{n-1}$ であることを示した。和の上端の理由も説明した。 |
| 階比型・階乗を使う演習 | 「倍率を吸収する」では、何で割るか、その結果どの因子が消えるかが分からない。 | 両辺を $n!$ で割ることと、$n!=n(n-1)!$ によって $n$ が消えることを説明した。積による解法と、割って式をそろえる解法は残した。 |
| 補助数列 | 「同じ更新をする量」だけでは、探す式の条件が曖昧。 | $g(n+1)=pg(n)+f(n)$ を満たす既知の式を探すこと、二つの式を引けば $f(n)$ が消えることを説明した。 |
| 解の組合せ | 「重複のない関係」「漸化式が2次元」では、数学的な対象が曖昧。 | 零数列を作る係数がすべて零に限られることを一次独立の定義として示し、次元は解全体について述べた。 |
| 定数項を消す型 | 不動点を「交点」と呼んでいた。また、図と式の引き算で入力の違いが説明されていなかった。 | 不動点は交点の $x$ 座標とした。図は同じ入力での定数項の違い、隣接する式の引き算は異なる入力を使うことを明記した。 |
| ガウス記号 | 「床を外す」などの省略や、強い帰納法の前提が未説明だった。 | 偶数・奇数に分けてガウス記号を外す操作を示し、帰納法で仮定する番号の範囲を説明した。 |
| ニュートン法 | 変形後の $b_{n+1}=b_n^2$ を、正値条件を示さず対数型へ結び付けていた。 | 二乗を繰り返して $b_n=b_1^{2^{n-1}}$ を得る導出とし、対数を取る方法は $b_1>0$ の場合に限って紹介した。 |
| 不変量 | 「目標から、一定であってほしい量を作った」では、その量を選ぶ理由を読み取る必要がある。 | $K$ が一定なら既知の隣接3項型になることを示してから、実際に一定かを確認する流れにした。 |
| 演習・行列・用語 | 「二基準点」「距離」「状態」「接線の交点」など、指す対象や意味が曖昧だった。 | 「二つの不動点」「差」「$(1,0)$ というベクトル」「曲線の接線と $x$ 軸の交点」など、その場の対象を示した。階比・平方完成の定義も修正した。 |

章節の構成、例題・演習の題数は維持した。抽象化、一般形、他分野との接続は、難しさだけを理由に削っていない。「更新」「追う量」「正規化」も一律には置換していない。
