# 章節の順序と参照リンクの整理

対象は `発展-new/`。第1～6章の大枠、基本パターンから定数型への導入、第3章の「解法を選ぶ→行き詰まったとき→答えの形を見通す」の説明順は維持する。

## 読む順序

- 応用パターンでは、総和型を階差等比複合型の直後へ移す。末尾に標準・応用演習へ進む案内を置く。
- 発展的な解法は、変数係数の一次型→特性方程式の解が虚数の場合→隣接多項型→非隣接2項型→ガウス記号を含む式の順とする。
- 一次分数型の「複素平面で見る」は第4章「虚数解型の別解と解釈」へ移し、「一次分数型には角度が残る」の前に置く。第2章には案内を残す。移動先で記号の意味が混ざらないよう、隣接3項型へ戻る際に定義を確認する。
- 「漸化式と行列」は連立型→隣接3項間→隣接2項間の順とする。「1つの行列で見渡す」と近似分数の応用は三つの表し方を学んだ後に置き、その後で一般の隣接多項間へ進む。
- 虚数解型の「指数と初項の番号」は表示の説明直後に、「二方向の階差」は微積分・ニュートン法の説明後に移す。
- ガウス記号の関連問題は難度順の続きではなく、テーマ別演習であることを示す。

## 見出しとラベル

原則として本文見出しを採用し、対応するラベルと参照側を同時に更新する。「隣接多項式」は扱う対象に合わせて「隣接多項型」へ改称し、旧「隣接4項型」の別名ラベルを統合する。

「問題」「方針」「和の公式」など同名の見出しでは、ラベルに親見出しを含めて一意性を保つ。見出しに数式を含む場合は、ラベルにTeX数式を入れず、その意味を表す文字列を使う。ファイルの `BOOK-FILE-ID` は維持する。

## 内部リンク

用語の導入文には既存の `bookterm`、解説への参照には `chapterref`・`sectionref`、例題番号には `bookproblemref` を使う。文脈上の「前節」は実際に参照する解説へ結び直す。問題・方針・解答間の既存の往復リンクは保つ。

GPT-6 Lunaの担当調査から得た候補を本文と照合して適用した。用語の全出現を機械的に置き換えず、導入箇所と明確な引用・参照を対象とした。

既存の参照検査に `booknavref` の参照先確認を追加し、章節・問題番号・用語集のリンクを検証する。
