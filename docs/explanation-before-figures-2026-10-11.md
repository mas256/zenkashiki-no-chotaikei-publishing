# 説明を読んでから図を見る配置

PR #39の現行原稿を土台に、本文・付録・巻末資料にある29図を確認した。21図を説明の後へ移し、図を挟んで一文が分断される箇所も整えた。21個のTeXファイルを変更している。

## 配置

| 対象 | 説明から図へ進む位置 |
| --- | --- |
| 等差数列の和 | 増分を逆順に組み合わせる理由と、和の式を説明してから模式図へ |
| 漸化式を解く前に | 具体的な置き換えと、元の項へ戻して確かめる流れの後へ |
| 基本4型 | 4型それぞれの説明・例題の後で、差と倍率のまとめとして示す |
| 一次分数型の図形的解釈 | 差の絶対値の比と偏角の差を説明した後へ |
| 隣接3項間 | 二項をまとめた量と、その等比的な更新を説明した後へ |
| 虚数解型 | 極形式から累乗の式を求め、回転と伸縮の意味を説明した後へ |
| ニュートン法 | 接線の式から次の近似値を求めた後へ |
| 初項依存型 | 更新式と初項を2にした計算の後に、既存の図の読み方と図を置く |
| 漸化式の分類 | 扱う範囲と各分類の意味を説明した後へ |
| 解法の決定・変更 | 観察・条件の確認・再評価と、行き詰まった理由の活用を説明した後へ |
| 行列の作用 | 行列・列ベクトル・掛け算を定義し、数値例で更新を確かめた後へ |
| 固有ベクトル | 定数倍になる二方向と、一般の方向を分ける計算を示した後へ |
| 連立型を見直す座標軸 | 斜めの二方向と、座標の見方を回す意味を説明した後へ |
| チェビシェフ多項式への入口 | 毎回同じ角を回す更新と、現在の角を倍にする更新の違いを説明した後へ |
| ラグランジュ補間 | 有限個の値に一致する延長を複数作れる理由の後へ |
| 差分・総和と微積分 | 差と和で互いに戻せる計算と、積分との対応を説明した後へ |
| 二項係数と差分 | 差を取る操作と逆に足し戻す操作の両方を説明した後へ |
| 三角関数の基本極限 | 面積を比較する条件と不等式を示した後へ |
| 複素平面と極形式 | 実軸・虚軸・距離・角度を定義した後へ |
| 複素数の積 | 積による偏角の加算と距離の倍率を説明した後へ |

章立ての図と特性方程式型の二図では、図を挟んでいた文を図の前で完結させた。演習の水平断面図では、網掛けと中心Oの説明を図の前へ移した。
床関数・三角関数型の単位円・ペル解の添字倍増・格子経路の図は、必要な説明が先にある配置を保持した。

## 文と記号

原文の説明段落を保ち、図の命令を移すことを基本とした。初項依存型では、既存の図の読み方の段落全体を、計算の後へ移した。
「図では」を「次の図では」にするなど、位置に合わせた指示語の修正を行った。
図の流れのまとめ、特性根の回転と伸縮、固有ベクトルの図中記号、補間の図の位置づけに短い補足を加えた。
複素数の積の図中の乗数は、本文で定義したcに合わせ、wzからczへ変更した。
