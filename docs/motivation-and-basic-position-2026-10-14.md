## 2.1.2と2.4の分担

2.1.2「四つの基本型の役割」では,等差・等比・階差・階比が後の解法の行き先になることを示す. 同じ数を足す・掛ける場合から,添字ごとに決まる量を足す・掛ける場合への関係も示す.

旧2.1.2の具体例,更新を追いやすい「きれいな形」の意味,追う量を作って元へ戻す流れ,その図は2.4へ集約した. `a_n+c`を候補にし,目標の更新から`c=3`を決める順に説明する. 次に引く・割る・項をまとめる方法へ進む. 「きれいな形」を案内する応用型の参照先も2.4へ変更した.

## 要約で弱くなった橋渡し

| 範囲 | 補った発想・流れ |
| --- | --- |
| 階差・階比 | 変化を足し戻す過程,倍率から階乗を候補にする理由,掛ける因子と割る因子の関係 |
| 定数項・多項式・指数 | 消したい項,左右に同じ量を作る目標,引く量を定数から添字の式へ広げる理由,指数で割る際の添字 |
| 一次分数・隣接3項 | 既知の型を目標にする理由,一つの差に残った分母を比で消す流れ,重解でも残る関係から復元できること |
| 連立・変数係数 | 和と差を選ぶ係数の対称性,隣り合う比から割る量を組み立てる手掛かり |
| 虚数根・対称式・三角関数 | 実数の項を作るために共役を組み合わせる理由,積を1にして定数項を打ち消す発想,二乗の更新を角度の倍化へ移す流れ |
| ニュートン法 | 曲線を接線で近似し,一次方程式の交点を次の値にする理由 |
| 解法選択・演習 | 一つの操作の結果が次の操作の入口になること,定数倍や階乗の因子を決める目標,動く基準から固定した基準への変換 |
| 行列・微積分・母関数 | 二項を一組として記録する理由,定数1を成分に持たせる意味,一歩の変化と足し戻し,添字を次数に移す理由 |
| 参照資料 | 部分分数分解で分母を選び,通分した分子を係数で合わせる手順 |

等差型の具体例,整数部分を群にまとめる証明,解を組み合わせる節など,すでに発想から計算までつながっている説明は保った. 等差型の連続代入は`n>=3`とし,`n=1,2`を直接確認する範囲も明示した. 用語・見出し・例題を増やすことより,既存の説明どうしをつなぐ短い段落を中心に補完した.
