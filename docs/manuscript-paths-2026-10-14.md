# 原稿ファイル名と章構成の対応

現行の発展版は,親のTeXファイルと,子ファイルを集めるフォルダを分けて配置する.
子ファイルを持たない原稿は,専用フォルダを作らず,対応する階層のフォルダへ直接置く.

## 入口と章

入口は `発展-new/漸化式の超体系的解説.tex`.
各章の入口ファイルは,章フォルダ内の同じ章タイトルの `.tex` である.
章内の子ファイルは `sections/`,その下の項は `subsections/`,さらに下の項は `subsubsections/` に置く.
第1章・第6章のように外部の子ファイルを読み込まない章には,空の `sections/` を作らない.

| 旧フォルダ | 現行フォルダ |
| --- | --- |
| 第1章 はじめに | 第1章 はじめに |
| 第3章 漸化式の解説 | 第2章 漸化式の解法 |
| 第4章 実際の解き方 | 第3章 解法の選択と演習 |
| 第5章 付録 | 第4章 解法の背景と広がり |
| 第7章 用語と計算の参照 | 第5章 用語と公式 |
| 第6章 参考文献 | 第6章 参考文献 |

## 親ファイルと子ファイル

基本パターンと分数型は,例えば次のように配置する.

```text
第2章 漸化式の解法/
├─ 漸化式の解法.tex
└─ sections/
   ├─ 02_基本パターン/
   │  ├─ 基本パターン.tex
   │  └─ subsections/
   │     ├─ 等差型.tex
   │     ├─ 等比型.tex
   │     ├─ 階差型.tex
   │     └─ 階比型.tex
   ├─ 定数数列.tex
   └─ 06_応用パターン/
      ├─ 応用パターン.tex
      └─ subsections/
         ├─ 特性方程式型.tex
         ├─ 階差等比複合型.tex
         └─ 04_分数型/
            ├─ 分数型.tex
            └─ subsubsections/
               ├─ 逆数型.tex
               ├─ 一次分数型.tex
               └─ 複素平面で見る.tex
```

この例では一部のファイルを省略している.
子ファイルを持つ項目だけフォルダを残し,その中は親ファイルと子ファイル用フォルダに分ける.
見出しのない導入原稿は,同じ親が読み込む `subsections/` に置く.

## 節の名前と順序

番号付きのフォルダ・ファイルは,実際の読み込み順に `01_`, `02_`, … と付けた.
途中の追加で生じた `04a_`, `04b_`, `01b_` などは使わない.
名前には現行見出しを用い,見出しに数式がある場合はPDFしおり用の短い名前を用いる.

第2章の `sections/` 内の入口ファイルは次の順である.

| 番号 | 入口ファイル |
| --- | --- |
| 01 | `01_漸化式を解く前に/漸化式を解く前に.tex` |
| 02 | `02_基本パターン/基本パターン.tex` |
| 03 | `定数数列.tex` |
| 04 | `追う量を変える.tex` |
| 05 | `解を組み合わせる.tex` |
| 06 | `06_応用パターン/応用パターン.tex` |
| 07 | `07_発展的な解法/発展的な解法.tex` |
| 08 | `08_式の構造を使う/式の構造を使う.tex` |
| 09 | `解法の分類.tex` |

例えば旧「隣接n項間漸化式型」は「隣接多項式」（4項間から一般の項数へ進む節）,旧「虚数解型隣接3項間漸化式」は「特性根が虚数の場合」に対応する.
発展的な解法では,変数係数の一次型を `01_` とし,ガウス記号を含む式を `02_` として,本文と同じ順にした.

第3章の演習は `sections/04_演習/subsections/` に置き,「演習の進め方 → 標準 → 応用 → 発展入門 → 発展 → 発展・特殊型 → 解法のつながり」の順にファイルを番号付けした.
問題そのものの混合順と問番号は変更していない.

第4章の節内へ切り出した説明も,その節の子ファイル用フォルダへまとめる.
「漸化式と行列」の「整数から作る近似分数」は `subsections/`,「二回分の更新」は見出しの階層に合わせて `subsubsections/` に置く.
「和と差から微積分へ」の「二項係数で多項式を表す」「二方向の階差」は `subsections/` に入る.

第5章は12節を `sections/` へ置き,目次と同じ順に番号を付けた.
用語の意味も入っていた旧「計算資料」フォルダを解消し,「等差数列の和」「指数と対数」「複素平面と極形式」などの現行見出しに合わせた.

## 参照とビルド

TeXの読み込み先,スマホ版の生成入口,検査スクリプト,CI,READMEとセットアップ手順を更新した.
`\input` のパスは親ファイルの所在によらず `発展-new/` を基準に指定する.
スマホ版も同じ基準ディレクトリからビルドする.
見出しのラベルと参照先は現行見出しに合わせ,同名の小見出しは親見出し名を付けて区別する.
本文の数式・演習番号は保持している.
公開PDFの名前は従来から書名・版番号で生成するため,配信URLの形式は変わらない.

基本版・`old/`・`発展-new/第4章 解法の背景と広がり/旧付録/` は過去の原稿として元の配置を保持する.
過去のレビューや改訂記録に現れる旧称・旧章番号は,その時点の記録である.
現在の原稿を探すときは,この対応と現行の目次を使用する.
