# 原稿ファイル名と章構成の対応

現行の発展版の書名・章立て・掲載順に,ファイル名とディレクトリ名を合わせた.
章の追加・移動前の名前や,旧見出しの名前が残っていたため,本文の目次から原稿を探しにくくなっていた.

## 入口と章

入口は `発展-new/漸化式の体系と解法.tex`.
各章の入口ファイルは,章フォルダ内の同じ章タイトルの `.tex` である.

| 旧フォルダ | 現行フォルダ |
| --- | --- |
| 第1章 はじめに | 第1章 はじめに |
| 第3章 漸化式の解説 | 第2章 漸化式の解法 |
| 第4章 実際の解き方 | 第3章 解法の選択と演習 |
| 第5章 付録 | 第4章 解法の背景と広がり |
| 第7章 用語と計算の参照 | 第5章 用語と公式 |
| 第6章 参考文献 | 第6章 参考文献 |

## 節の名前と順序

番号付きのフォルダ・ファイルは,実際の読み込み順に `01_`, `02_`, … と付けた.
途中の追加で生じた `04a_`, `04b_`, `01b_` などは使わない.
名前には現行見出しを用い,見出しに数式がある場合はPDFしおり用の短い名前を用いる.

第2章の節フォルダは次の順である.

| 番号 | フォルダ |
| --- | --- |
| 01 | 漸化式を解く前に |
| 02 | 四つの基本型 |
| 03 | 定数数列 |
| 04 | 追う量を変える |
| 05 | 解を組み合わせる |
| 06 | 七つの応用型 |
| 07 | 発展的な解法 |
| 08 | 式の構造を使う |
| 09 | 解法の分類 |

例えば旧「隣接n項間漸化式型」は「隣接4項型」,旧「虚数解型隣接3項間漸化式」は「特性根が虚数の場合」に対応する.
発展的な解法では,変数係数の一次型を `01_` とし,ガウス記号を含む式を `02_` として,本文と同じ順にした.

第3章の演習は「演習の進め方 → 標準 → 応用 → 発展入門 → 発展 → 発展・特殊型 → 解法のつながり」の順にファイルを番号付けした.
問題そのものの混合順と問番号は変更していない.

第4章の節内へ切り出した説明は,その節のフォルダへまとめた.
「二回分の更新」「整数から作る近似分数」は「漸化式と行列」,「二項係数で多項式を表す」「二方向の階差」は「和と差から微積分へ」に入る.

第5章は12節を章フォルダへ直接置き,目次と同じ順に番号を付けた.
用語の意味も入っていた旧「計算資料」フォルダを解消し,「等差数列の和」「指数と対数」「複素平面と極形式」などの現行見出しに合わせた.

## 参照とビルド

TeXの読み込み先,スマホ版の生成入口,検査スクリプト,CI,READMEとセットアップ手順を更新した.
本文の説明・数式・ラベル・演習番号は保持している.
公開PDFの名前は従来から書名・版番号で生成するため,配信URLの形式は変わらない.

基本版・`old/`・旧付録は過去の原稿として保持する.
過去のレビューや改訂記録に現れる旧称・旧章番号は,その時点の記録である.
現在の原稿を探すときは,この対応と現行の目次を使用する.
